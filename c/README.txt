Cá Ngựa 3D — Offline test v2
============================

Mở index.html bằng Chrome trên điện thoại (cùng thư mục).

Luồng mỗi lượt:
1. Popup giữa màn hình: LẮC
2. Full-screen Lac_hop.html + a3a.mp3 (lắc hộp)
3. Full-screen Mat_N.html + a3b.mp3 (mở hộp, N đã random sẵn)
4. Trở lại bàn — nút 3D lơ lửng trên ô đích
5. Chạm nút 3D → quân nhảy TỪNG BƯỚC (5 nút = 5 lần nhảy)

Âm thanh:
- a3a.mp3 = lắc hộp (hiện đang copy từ a2 — hãy thay file thật)
- a3b.mp3 = mở hộp (hiện đang copy từ a1 — hãy thay file thật)

board.html giữ hình học gốc (đường đi + màu).
